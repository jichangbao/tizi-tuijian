## 五、新手买梯子避坑

1. **第一次先买月付或小包**，用一个晚高峰再决定要不要年付。（[月付还是年付？](https://tiziking.com/zhishi/yuefu-nianfu/)）
2. **看线路类型**：IPLC / IEPL 专线晚高峰更稳，公网直连便宜但容易卡。（[专线和中转的区别](https://tiziking.com/zhishi/zhuanxian-zhongzhuan-qubie/)）
3. **别信“永久”“不限速不限量”**，正规梯子都按流量或时长计费。
4. **只在官网下单**，不要在群里扫个人收款码。
5. **免费节点只能临时应急**，隐私和稳定性都没保障。（[免费梯子安全吗](https://tiziking.com/zhishi/mianfei-vpn-anquan/)）

## 六、常见问题

**梯子是什么？和 VPN、机场有什么区别？**
梯子是翻墙工具的俗称；“机场”指提供代理节点订阅的服务商，用 Clash、小火箭等客户端导入订阅即可使用。详见 [梯子是什么](https://tiziking.com/zhishi/tizi-shi-shenme/)。

**买了梯子怎么用？**
复制订阅链接 → 导入客户端 → 选节点 → 打开代理。步骤见 [订阅导入教程](https://tiziking.com/jiaocheng/daoru-dingyue/)，客户端见 [客户端下载](https://github.com/jichangbao/tizi-kehuduan)。

**梯子连不上怎么办？**
先校准系统时间、更新订阅、换节点，再看 [梯子连不上怎么办](https://tiziking.com/jiaocheng/tizi-lian-bu-shang/)。

**iPhone 下载不了小火箭？**
需要外区 Apple ID，见 [美区 Apple ID 注册教程](https://tiziking.com/jiaocheng/meiqu-apple-id-zhuce/)。
